# 見えている僕と、見えない僕

城山優太本人について、人生・思考・得意不得意・負荷・発散・障害理解まで含めて伝える、フルカラー漫画PDF制作リポジトリ。

## Claudeへ

**最初に [`CLAUDE.md`](./CLAUDE.md) を全文読んでください。**

次に [`docs/QA_CHECKLIST.md`](./docs/QA_CHECKLIST.md) と [`assets/reference/README.md`](./assets/reference/README.md) を確認し、Issue #1 の制作指示も参照してください。

### ゴール

単なる「イラスト付き説明資料」ではなく、日本の学習漫画のように、場面・人物・表情・会話・心の声・ナレーションで人生を追える漫画を作る。

最終的には、**全部読めば「城山優太という人がかなりわかる」完成漫画PDF**にする。

### 重要

- 絵が主役、文章は補助
- 事実と異なる創作は禁止
- 重要事項を勝手に削らない
- 文字化け・誤字・意味不明文字は禁止
- 各ページを拡大校閲してから確定
- 全ページ完成後に再度全件検品
- 完成条件を満たすまで「完成」と報告しない

## 推奨ディレクトリ

```text
assets/
```

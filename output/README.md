# output/

完成PDFを置くディレクトリ。

## 用途

- `pages/final/` に全ページが揃い、`docs/QA_CHECKLIST.md` の全項目（1〜5すべて）を満たした
  後にのみ、ここへ最終PDFを書き出す。
- ファイル名の目安: `見えている僕と、見えない僕.pdf`（確定稿）。
  改訂を重ねる場合はバージョンや日付を付与する（例: `..._v2_20260907.pdf`）。

## 提出前の必須確認（`CLAUDE.md` 最終検品より）

- 全ページをPDFから再レンダリングし、拡大確認した
- ページ順が正しい
- 余白・裁ち落とし・印刷範囲に問題がない
- 画像が低解像度になっていない
- 内容の不要な重複がない
- 最初から最後まで一本のストーリーになっている
- 重要事項の脱落がない
- 印刷可能なPDFとして正常に開ける

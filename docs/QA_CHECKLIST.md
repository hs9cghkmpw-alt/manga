# QA CHECKLIST

このチェックリストは、各ページ確定時と最終PDF完成前の両方で使う。

## 1. 事実
- [ ] 本人が話した事実、または確認済み資料に根拠がある
- [ ] 推測を事実として描いていない
- [ ] 年齢・時系列に矛盾がない
- [ ] 母の離婚を本人の離婚と誤記していない
- [ ] 12歳の時期を「受験期」と誤記していない。「思春期・反抗期」
- [ ] 自衛隊を「楽だった」としていない
- [ ] 「自衛隊が厳しかったから壊れた」と単純化していない
- [ ] 会話不能な人物として描いていない
- [ ] 人の気持ちが自然に読めると断定していない

## 2. 日本語
- [ ] 見出しを全文読んだ
- [ ] 吹き出しを全文読んだ
- [ ] 心の声を全文読んだ
- [ ] ナレーションを全文読んだ
- [ ] 小さい注記を全文読んだ
- [ ] 背景に意味不明なAI文字がない
- [ ] 看板、書類、ノート、画面内文字を確認した
- [ ] 誤字なし
- [ ] 脱字なし
- [ ] 文字化けなし
- [ ] 文字切れなし
- [ ] 文字の重なりなし

## 3. 漫画表現
- [ ] 絵が主役になっている
- [ ] 文章ボックスだけで話を進めていない
- [ ] 人物が背景込みの場面の中にいる
- [ ] 1ページ内で複数コマ・時間経過・視線誘導が成立している
- [ ] 表情と姿勢で感情・負荷が伝わる
- [ ] 同じ人物絵の使い回しでページを水増ししていない
- [ ] PowerPoint／パンフレット風になっていない
- [ ] 学習漫画として自然に読める

## 4. 重要テーマ
- [ ] 「できる」≠「楽にできる」が伝わる
- [ ] 「普通に見える」≠「余裕がある」が伝わる
- [ ] 「しっかりしなきゃ」の仮面モチーフがつながっている
- [ ] 管理の苦手さだけでなく「仕組みがあればできる」も描けている
- [ ] 自分の努力で改善できる問題／できない問題の差が描けている
- [ ] 脳疲労が描けている
- [ ] 発散を安全に探したいというテーマが描けている
- [ ] 「介助より理解」が終盤の中心テーマになっている
- [ ] 本人を支援対象者だけでなく、夫・父・元自衛官・支援員経験者・IT好き・趣味を持つ人として描けている

## 5. 最終PDF
- [ ] 全ページをPDFから再レンダリングした
- [ ] 再レンダリング画像を全ページ拡大確認した
- [ ] ページ順が正しい
- [ ] 全ページの余白・裁ち落とし・印刷範囲に問題がない
- [ ] 画像が低解像度になっていない
- [ ] 同じ内容の不要な重複がない
- [ ] 最初から最後まで一本のストーリーになっている
- [ ] 重要事項の脱落がない
- [ ] 印刷可能なPDFとして正常に開ける

## 完成判定
上記に1つでも未確認・未修正がある場合は「完成」と報告しない。

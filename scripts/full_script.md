## P00 扉ページ（タイトル）

**ねらい**: 作品全体のトーン提示。「診断名やできる／できないだけでは分からない人」という導入。

**コマ構成**
1. （大ゴマ）現在の城山優太が窓辺で少し考え込むような、しかし穏やかな一場面。表情には「仮面」の薄い光効果を軽くかける。
2. 小コマの連なり（幼少期・自衛隊・現在の3カット、シルエット気味）で「一人の人生」を予告。

**テキスト**
- タイトル: 『見えている僕と、見えない僕』
- ナレーション: 「これは、誰か一人の障害についての説明書ではありません。」
- ナレーション: 「一人の人間が、どう考え、どう工夫し、どう壊れて、どう生きているかの記録です。」

## P01 幼少期 — 兄弟の中で

**根拠**: 幼少期／長男・弟3人。

**コマ構成**
1. 自宅の居間、幼い優太が弟3人と遊んでいる賑やかな場面。
2. 母が「お兄ちゃんなんだから」と優太を叱る場面。優太は不満そうな顔ながらも我慢している。
3. 弟の一人が優太に懐いている描写（信頼されている長男像）。

**テキスト**
- ナレーション: 「長男として生まれ、下に三人の弟がいた。」
- 母（セリフ）: 「お兄ちゃんなんだから、ちゃんとして。」
- 心の声（優太）: 「……なんで、いつも僕なんだろう。」
- ナレーション: 「それでも家の中では、弟たちとよく遊ぶ、にぎやかな時間があった。」

## P02 7歳 — 最初の別れ

**コマ構成**

4. 教室で誰も知らない顔に囲まれ、俯く優太。

**テキスト**

- ナレーション: 「人生で初めての転校。友達と離れるのも、これが初めてだった。」

**テキスト**

## P05 中学校 — にぎやかな日々とルールの読み方

**根拠**: 「勉強さえできていればいいんだろう」／かなりふざける／提出物ほぼ出した記憶がない／締切直前に友達のものを写す／朝ギリギリまで寝る／友達の迎えで起きられる／担任が来る時間の把握／友達に恵まれる／いじりを「構ってもらえている」と感じることも。

**コマ構成**
1. 教室で友達を笑わせている優太（よく喋る、人気者の一面）。
2. 提出物の山を前に「あとで写せばいい」と考えている優太。
3. 締切直前、友達のノートを覗き込んで一気に写す場面。
4. 「担任は今の時間はまだ来ない」と時計を見ながら余裕の表情。
5. 朝、友達が迎えに来てようやく起き上がる場面。

**テキスト**
- 心の声: 「勉強さえできていれば、それでいいんだろう。」
- ナレーション: 「学校ではよくふざけて、提出物はほとんど出した記憶がない。」
- 心の声: 「……これ、明日でいいや。」
- ナレーション: 「必要なときは、締切直前に友達のものを一気に写した。」
- ナレーション: 「朝はギリギリまで寝ていて、友達が迎えに来ることでようやく起きられることもあった。」
- 心の声: 「今の時間なら、担任はまだ来ない。セーフ。」
- ナレーション: 「学校の実際のルール——建前ではなく本当の運用——は、よく分かっていた。」
- ナレーション: 「よく喋る子で、友達には恵まれた。強くいじられることもあったが、当時はそれを『構ってもらえている』と嬉しく感じることもあった。」

## P06 12歳の転機 — 二度目の別れ

**根拠**: 母の2回目の離婚。DVが原因。母だけでなく本人もかなり暴力を受けた。離れて正解だったと考えている。

**コマ構成**
1. 家庭内の緊張した空気（直接的な暴力描写は避け、割れた食器や身をすくめる優太の背中など、示唆的な構図で表現）。
2. 母をかばうように前に出る幼い優太。
3. 家を出る母子の後ろ姿。
4. 少し時間が経った後の優太の表情——安堵と、まだ整理できない気持ちが同居している。

**テキスト**
- ナレーション: 「12歳のとき、母は二度目の離婚をした。理由は、DVだった。」
- ナレーション: 「母だけでなく、優太自身もかなりの暴力を受けていた。」
- 心の声（現在の優太のモノローグとして）: 「離れたのは、正解だったと思う。」
- ナレーション: 「それでも、以前はこう思おうとしていた。」

## P07 壊れた父子関係の試み

**根拠**: 「どうすればこの人をお父さんと呼べるだろう」「好きになろう」／その試みも途中で壊れた／再び転校、友達と離れる／「受験期」ではなく「思春期・反抗期」。

**コマ構成**
1. 幼い優太が、義理の父となる相手に対してぎこちなく歩み寄ろうとする場面。
2. 「お父さん」と呼ぼうとして、言葉に詰まる優太。
3. その関係が壊れていく様子を示す、静かな一コマ（会話のない食卓など）。
4. 三度目の転校、また友達と離れる優太の背中。

**テキスト**
- 心の声: 「どうすれば、この人をお父さんと呼べるだろう。」
- 心の声: 「好きになろう。そう思っていた時期もあった。」
- ナレーション: 「けれど、その関係を作ろうとする試みも、途中で壊れてしまった。」
- ナレーション: 「またしても転校し、友達と離れることになった。」
- ナレーション: 「世間的には『受験期』と呼ばれる年齢だったが、優太にとってこの時期は、はっきりと『思春期・反抗期』だった。」

## P08 「しっかりしなきゃ」— 仮面の始まり

**根拠**: 母から「助けて」と言われたことを明確に覚えている／「自分がしっかりしなきゃ」／「一枚皮をかぶった」「仮面みたいなもの」。

**コマ構成**
1. 母が優太に向かって「助けて」と漏らす、印象的な一コマ（大ゴマ）。
2. その言葉を受け止める優太の顔——一瞬子どもの表情が消える。
3. 鏡や窓ガラスに映る優太の顔に、薄い光の膜（仮面モチーフ）がかかる演出コマ。
4. 以降のページで繰り返し使う「仮面」の視覚記号をここで初めて明示的に提示する。

**テキスト**
- 母: 「助けて……。」
- ナレーション: 「その言葉を、優太ははっきりと覚えている。」
- 心の声: 「……僕が、しっかりしなきゃ。」
- ナレーション（本人の表現）: 「本人はこの感覚を、『一枚皮をかぶった』『仮面みたいなもの』と表現する。」
- 説明枠（図解コマ）: 「この“仮面”は、この後も物語の中で繰り返し登場する。」

## P09 管理の苦手さと、合う仕組み

**根拠**: 忘れ物・提出物・準備・持ち物・予定・お金の管理が苦手／仕組みを作ればできることもある／お金を缶に入れて簡単に取り出せなくすると貯められた／「本人に合う外部構造があるとできることが増える」。

**コマ構成**
1. 散らかった机、予定を忘れて慌てる優太（一般化した日常のワンシーンとして、深刻になりすぎない描写）。
2. 缶にコインを入れている優太——簡単に取り出せない構造にしてあることが分かる作画（蓋がテープで留められている等）。
3. 缶が徐々に重くなっていく時間経過のコマ。
4. 説明枠（図解）: 「できない人」ではなく「合う仕組みがあればできる人」というテーマの明示。

**テキスト**
- ナレーション: 「忘れ物、提出物、持ち物、予定、お金——管理が必要なものは、昔からずっと苦手だった。」
- 心の声: 「気づいたら、もう間に合わない。」
- ナレーション: 「けれど、『仕組み』を作れば、できることもあった。」
- ナレーション: 「たとえばお金は、缶に入れて簡単に取り出せなくすることで、貯められた。」
- 説明枠: 「『できない人』なのではない。本人に合う外部の仕組みがあると、できることが増える。」

## P11 連帯責任という構造

**根拠**: 忘れ物やミスが起きても全員でカバーし連帯責任で最後まで解決する構造／本人だけが「できない人」として突出する構造ではなかった／厳しい環境への耐性もあった。

**コマ構成**
1. 誰かの忘れ物・ミスが発覚し、同期全員が動き出す場面。
2. 優太自身もミスをして、仲間にフォローされる場面（対等な立場として描く）。
3. 全員で問題を解決し終えた後の、疲れながらも達成感のある表情。
4. 説明枠: この構造が持つ意味を言語化。

**テキスト**
- ナレーション: 「ミスや忘れ物が起きても、そこにいる全員でカバーし、連帯責任で最後まで解決する。それがこの場所のルールだった。」
- 同期: 「大丈夫だ、一緒にやる。」
- 心の声: 「ここでは、僕だけが『できない人』として浮くわけじゃない。」
- 説明枠: 「みんなが同じ厳しい環境にいた。優太には、その厳しさに耐える力もあった。」

## P12 ルールとの付き合い方

**根拠**: 基本的にルールを覚える／違反には厳しくなることも／矛盾・理不尽には強く反発／詰められれば理屈で詰め返す／「生意気」と言われることも／「年齢ではなく内容を見てほしい」／「早く歳を取りたい」。

**コマ構成**
1. 規則を淡々と、しかし確実に覚え守る優太。
2. 誰かがルールを破るのを見て、厳しい表情で注意する優太。
3. 理不尽な指示に対して、理屈で反論する優太と、それを苦々しく思う年上の相手。
4. 「生意気だ」と言われ、納得いかない表情の優太。

**テキスト**
- ナレーション: 「ルールは基本的にきちんと覚える。ただし違反には、自分自身にも他人にも厳しくなることがあった。」
- ナレーション: 「一方で、ルールそのものに矛盾や理不尽を感じると、強く反発した。」
- 優太: 「納得できません。理由を説明してください。」
- 上官/年長者: 「生意気なやつだ。」
- 心の声: 「年齢じゃなくて、言っている中身そのものを見てほしいんだ。」
- 心の声: 「早く、歳を取りたい。」

## P13 通信の仕事 — 努力で変えられる問題

**根拠**: 防衛マイクロ回線の運用など通信関係／仕事を覚えれば運用できる／トラブルはチームで復旧／失敗しても「もっと勉強しよう」「もう少しやれたな」と自分の努力へ変換できた＝努力で改善できる問題だった。

**コマ構成**
1. 通信機器の前で真剣に作業する優太。
2. トラブル発生、警告灯や慌ただしい様子。
3. チームで協力し、通信を復旧させる場面。
4. 復旧後、悔しさの残る表情で機材をメモする優太（次への糧にしている描写）。

**テキスト**
- ナレーション: 「配属されたのは、防衛マイクロ回線の運用など、通信に関わる仕事だった。」
- ナレーション: 「仕事を覚えれば、運用できるようになる。トラブルが起きても、最終的にはチームで通信を復旧させた。」
- 心の声: 「もっと勉強しよう。」
- 心の声: 「もう少し、やれたはずだ。」
- 説明枠: 「失敗しても、自分の努力に変換できる——それは『自分が頑張れば改善できる問題』だった。」

## P15 板挟み — 崩れていく歯車

**コマ構成**

3. 夜勤・災害対応・仮眠中の呼び出しなど、休む間もない状況を複数の小コマで畳みかける。

**テキスト**

## P16 精神的に壊れた時期

**根拠**: これらが重なって精神的に壊れた／「自衛隊が厳しかったから壊れた」と単純化しない／本人に特に危険なのは「自分がどれだけ考え、努力しても、自分ではどうにもできない問題が続くこと」。

**コマ構成**
1. 静かで彩度の低いコマ、優太が一人でうずくまるように座っている。
2. 過去の努力の記憶（P13の通信の場面）がフラッシュバックのように差し込まれる。
3. 説明枠（図解）: 何が本人を追い詰めたのかを言語化する重要な解説コマ。

**テキスト**
- ナレーション: 「厳しい訓練にも、厳しい上下関係にも、優太には耐える力があった。」
- ナレーション: 「けれどこのとき、積み重なった条件が違った。」
- 説明枠: 「『自衛隊が厳しかったから壊れた』という単純な話ではない。」
- 説明枠: 「本人にとって特に危険なのは——『自分がどれだけ考え、努力しても、自分ではどうにもできない問題が続くこと』。」

## P22 介助より理解（最重要・終盤）

**根拠**: 常に助けてほしいわけではない／できることは自分でやりたい／介助が必要な時は基本的に自分から相談する／余裕がなくなると相談自体できないことも／一番欲しいのは理解者／「普段こういうふうに頭を使っているんだ」と知っていれば「今の状況なら結構きついかもしれない」と考えられる／毎回「大丈夫？」と聞く必要はない／声をかける・待つ・情報整理・予定調整・何もしない、その時々で対応は違う／「本人を理解した上でその時どうするかを考える」＝これが障害理解だと本人は考えている。

**コマ構成**
1. 優太が、あえて手伝いを断る場面(「自分でやりたい」という意思の描写)。
2. 本当に余裕がなくなった時、相談することさえできずに黙り込んでしまう場面(対比として重要)。
3. 周囲の人物(訪問看護師・支援者などを象徴する人物)が、優太の「普段の頭の使い方」を理解している上で、様子を見ながら適切な距離を取る場面。
4. 説明枠(図解): 「声をかける／待つ／情報を整理する／予定を調整する／何もしない」の5つの選択肢を並べた図解。
5. 優太の心の声として、本人の言葉をそのまま使う。

**テキスト**
- ナレーション: 「優太は、いつも助けてほしいわけではない。できることは、自分でやりたい。」
- ナレーション: 「介助が必要なときは、基本的には自分から相談する。」
- ナレーション: 「ただし、本当に余裕がなくなると、相談すること自体ができなくなる場合もある。」
- 心の声: 「一番欲しいのは……分かってくれる人。」
- 説明枠: 「周囲が『この人は普段こういうふうに頭を使っているんだ』と知っていれば、『今の状況なら、普通に見えていても結構きついかもしれない』と考えられる。」
- 説明枠: 「理解したからといって、毎回『大丈夫?』と声をかける必要はない。声をかける。待つ。情報を整理する。予定を調整する。何もしない。必要な対応は、その時によって違う。」

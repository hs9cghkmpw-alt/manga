# スタイルガイド — 『見えている僕と、見えない僕』

`CLAUDE.md` の「最重要ビジュアル方針」「禁止」節と矛盾した場合は `CLAUDE.md` を優先する。

## 1. 全体トーン

- 日本の学習漫画／進研ゼミ漫画に近い、親しみやすいフルカラー漫画。
- 医療パンフレットのように無機質・硬質になりすぎない。
- ギャグ漫画のようなデフォルメ・誇張表現には寄せない（表情は誇張しすぎず、実在の人物として説明できる範囲）。
- 「资料」ではなく「物語」として最初のページから最後のページまで自然に読める画作り。

## 2. 画風

- 線: 中太のクリーンな線画。デジタル彩色。輪郭線は黒〜濃い茶で統一。
- 彩色: フルカラー、セルシェーディング＋簡易グラデーション。厚塗りすぎない、学習漫画的な平坦さ寄り。
- 背景: 単純化しすぎず、場面（教室・自宅・基地・オフィス・釣り場など）が具体的にわかる書き込み量を持たせる。
- 人物は必ず背景の中の一場面に存在させる。背景を省略した「アイコン単体+吹き出し」構成は禁止。

## 3. キャラクターデザイン — 城山優太

実写参照がまだない前提で、年代を通して一貫した特徴を保つための暫定デザイン基準。実画像が届き次第、
以下を実画像に合わせて修正する。

### 共通ルール
- 全年代を通じて「顔の骨格・目の形・眉の角度」を統一し、年代が変わっても同一人物と分かるようにする。
- 体格は年代に応じて自然に成長させる（幼少期は小柄、自衛隊時代は鍛えられた体格、現在はやや落ち着いた成人体型）。
- 表情のレンジは豊か（笑う・困る・疲れる・苛立つ・安堵する）にしつつ、常時ぐったりした「介助が必要な人物」には描かない。

### 年代別
| 年代 | 髪型・服装の目安 | 表情の基調 |
|---|---|---|
| 幼少期（7歳前後） | 短髪、私服、やや幼い丸みのある輪郭 | 素直・寂しさが出る場面あり |
| 小学校 | 短髪、通学服／私服 | 好奇心・集中している顔が多い |
| 中学校 | やや伸びた髪、学生服 | よく喋る・ふざける表情、時々気だるげ |
| 高等工科学校〜自衛隊 | 短髪（規定）、迷彩・作業服・制服 | 引き締まった表情、疲労が滲む場面あり |
| 現在（成人） | 短めの社会人的な髪型、私服／支援先での服装 | 落ち着き＋時折見える疲れ・生真面目さ |

### 家族
- 母: 明確な容姿情報がないため、年代を通じて一貫した一般的な成人女性として描き、詳細な創作（服装のブランド等）はしない。
- 弟3人: 幼少期の集団シーンでのみ登場。個別の人格描写はせず「兄弟で遊ぶ」情景の一部として扱う。
- 妻・子ども: 現在パートの家庭シーンにのみ登場。関係性（夫・父）が伝わる構図を優先し、詳細な容姿は創作しすぎない一般的な描写に留める。

## 4. 「仮面」モチーフの視覚化ルール

12歳の転機以降、全編を貫く最重要ビジュアルモチーフ。

- ホラー的な仮面そのもの（お面オブジェクト）を持たせない。
- 表現方法: 顔の半分に薄い光の膜／半透明のレイヤーがかかったような効果、または表情と姿勢の間に
  わずかな「作っている感じ」を出す（口角は上がっているが目が笑っていない、姿勢だけ良い、等）。
- 心の声（内面）と吹き出し（表面上の発言）を意図的に食い違わせるコマ構成で「仮面」を可視化する。
- 本人が「仮面を外せている」場面（家族といる時、信頼できる相手といる時）は、同じ効果を外して素の表情で描く。
- 終盤「介助より理解」パートでは、理解者と接する場面で仮面が薄くなっていく変化を見せる。

## 5. コマ割り・演出ルール

- 1ページあたり4〜8コマを基本とし、場面の重要度に応じてコマサイズを変える（山場は大ゴマ）。
- 視線誘導は日本語の右上→左下の読み順に従う。
- 同じ構図・同じ人物絵の使い回しでページを水増ししない（`CLAUDE.md` 禁止事項）。
- 1ページの中で時間経過・場面転換が起きてよい（例: 朝の支度→登校→教室、の3段階を1ページで見せる）。
- 図解・強調文字は「学習漫画の説明コマ」として、通常コマと区別できるデザイン（枠線・背景トーンを変える）で挿入する。

## 6. テキスト要素の使い分け

| 要素 | 用途 | 見た目の目安 |
|---|---|---|
| 吹き出し | 声に出したセリフ | 実線の楕円吹き出し、尻尾で発話者を示す |
| 心の声 | 口に出していない内面 | 雲形吹き出し、または点線の吹き出し |
| ナレーション | 場面説明・時間経過・地の文 | ページ上部/下部の矩形ボックス、背景は白〜薄いクリーム色 |
| 説明枠・図解 | 脳疲労の説明など概念の可視化 | 点線枠・簡易アイコンや矢印を用いた図解コマ |
| 強調文字 | 感情のピーク、決定的な一言 | 手書き風の強調フォント、コマからはみ出してよい |
| 擬音 | 環境音・動作音 | 手書き風の効果音文字、背景に溶け込ませる |

## 7. 配色ルール

- 幼少期〜小学校: 明るく柔らかい暖色中心。
- 7歳・12歳の転機の場面: 彩度を落とし、寒色を混ぜて「寂しさ・緊張」を表現するが、全ページが暗くならないよう
  同じページ内に他の色温度のコマも混在させる。
- 自衛隊パート: 硬質なグレー・カーキ・紺を基調にしつつ、仲間との場面では暖色を差し込み「厳しいが孤立ではない」ことを示す。
- 精神的に壊れた時期: 最も彩度が低く、コントラストの強い画面。ただし常時介助が必要な人物には見せない。
- 現在パート（家族・支援・趣味）: 全体を通じて最も温かみのある配色に回帰させ、「理解のある中で生きていく」着地点を色でも表現する。

## 8. 日本語タイポグラフィルール

- 画像生成AIに直接日本語を描かせない。生成後にAI文字を除去し、正規の日本語フォント（例: 源柔ゴシック／BIZ UDゴシック等の実在するフリーフォント、最終選定は組版時に確認）で後組みする。
- 誤字脱字、文字切れ、文字重なりは禁止。組版後に必ず拡大して全文を読む（`docs/QA_CHECKLIST.md` 準拠）。
- 吹き出し内テキストは吹き出りサイズに収まるよう文字数を調整し、はみ出しは禁止。

## 9. 絶対禁止事項（`CLAUDE.md` より再掲・遵守）

- 文章中心の「イラスト付き説明資料」
- 丸い人物アイコン＋巨大テキストボックス主体
- PowerPoint／パンフレットのような構成
- 年表を並べただけの構成
- 1ページに人物の顔1つ＋残り文章
- 同じ人物絵の使い回し＋文章だけ変更
- 元画像の単純分割
- 本人が言っていない事実・感情の創作
- 診断名からの内面の勝手な推測
- 重要事項の要約削除
- 「普通に会話できない人」として描くこと
- 「自衛隊が厳しかったから壊れた」という単純化
- 常時介助が必要な人物としての描写
- AIの崩れた日本語の採用

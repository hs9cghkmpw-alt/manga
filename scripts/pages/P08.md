# P08 — 人に合わせてきた人生

## 漫画構成
1. 学校・家庭・集団で周囲を観察する優太。
2. 『郷に入れば郷に従う』ように、その場のルールを覚えて合わせる。
3. ルール違反には厳しくなる一方、矛盾したルールには反発。
4. 若さを理由に『生意気』と扱われる。

## 本文
ナレーション「人に合わせてきた人生でした。」
ナレーション「郷に入れば郷に従う。その場所で何が普通なのかを見て、覚えて、合わせる。」
ナレーション「ルールを理解すると、違反する人に厳しくなることもあった。」
心の声「でも、そのルール自体が矛盾しているなら、納得できない。」
ナレーション「理不尽に詰められれば、理屈で詰め返すこともあった。」
ナレーション「若い頃は『生意気』で片づけられることもあって、早く歳を取りたいと思っていた。」
心の声「年齢じゃなくて、言っている内容を見てほしい。」

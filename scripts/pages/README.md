# 『見えている僕と、見えない僕』ページ別確定台本

このディレクトリの P00〜P23 を画像生成・漫画制作の正本とする。

## 全体の流れ
現在の「普通に見える僕」から入り、幼少期→二度の離婚と転校→12歳の「助けて」と仮面→学校生活で身につけた工夫→高等工科学校・自衛隊→自分で改善できる問題と、自分ではどうにもできない問題の違い→精神的に壊れた時期→その後の多職種経験→支援する側から支援される側へ→現在の認知処理・脳疲労・発散→家族と生活→『介助より理解』→これから、の順で一本の人生として読む。

## 絶対原則
- ユーザー本人が伝えた事実を曲げない。診断名から感情・行動を創作しない。
- 「できる」≠「楽にできる」、「普通に見える」≠「余裕がある」を全編の軸にする。
- 会話ができない人として描かない。会話できるが、内部では観察・照合・仮説・応答・更新を大量に行う。
- 自衛隊が厳しかったから壊れた、とは描かない。危険なのは、自分が努力しても動かせない問題を背負い続ける構造と、夜勤・長時間拘束・睡眠不足等の累積。
- 12歳は「受験期」ではなく「思春期・反抗期」。
- 母との関係は「縁を切りたい」ではない。障害事由・特性をある程度理解してほしい。
- 常時介助を求めている人物として描かない。中心は「介助より理解」。
- 絵・場面・人物・漫画表現を主役にし、説明は必要十分に入れる。

# P23 — 壊れる前に、一緒に考える

## 役割
『助けてください』だけで終わらず、理解を土台にした今後へ着地する。

## 漫画構成
1. 再就職へ向けて準備する現在の優太。
2. 事前共有、優先順位整理、短い回復、相談できる関係など、働き始める前から仕組みを作る。
3. 家族・支援者・職場と、それぞれ適切な距離でつながる。
4. 最後は仮面を完全に捨てるのではなく、必要な社会適応を持ちながら『内側も知ってもらえている』状態。

## 本文
ナレーション「僕は、何もできない人になりたいわけではない。これからも働きたいし、家族の中で生きていきたい。」
ナレーション「だから、問題が起きて壊れてから対処するのではなく、その前から考えておきたい。」
ナレーション「何が負荷になるのか。どうすれば減らせるのか。どうすれば安全に頭を休められるのか。相談できないほど余裕がなくなった時、周りはどう気づけるのか。」
ナレーション「『普通に見えるから大丈夫』でも、『障害があるから何でも助ける』でもない。」
優太「僕を知った上で、その時いちばんいい方法を、一緒に考えてほしい。」
締め「見えている僕と、見えない僕。その両方が、僕です。」

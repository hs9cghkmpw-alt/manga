# 画像生成プロンプト集（日本語版）

`scripts/00_style_guide.md` と `scripts/full_script.md` に基づく、ページ単位の画像生成用プロンプト。

## 共通ルール（全ページ共通・プロンプト冒頭に必ず付与）

```
フルカラー、日本の学習漫画／進研ゼミ漫画スタイル、デジタル彩色、クリーンな中太線画、
1ページに複数コマ構成、人物は背景込みの場面の中に配置、
表情と姿勢と構図で感情が伝わる演出、PowerPointやパンフレット風のレイアウトにしない、
丸いアイコン肖像＋テキストボックスの構図にしない。
重要: 画像内に日本語テキスト・吹き出し文字・ナレーション文字は生成しない。
コマ割り・背景・人物・空白の吹き出し枠の形だけを生成し、文字は後工程で正規フォント組版する。
吹き出し・心の声（雲形）・ナレーション枠・説明枠は「空白の枠」として描画する。
```

参照画像 `assets/reference/style_reference.jpg` が入手でき次第、上記共通ルールに加えて
image-to-image／スタイル参照として併用すること（現状は未入手のため文章指定のみで運用）。

### P00 扉ページ
現在の城山優太（成人男性、落ち着いた私服）が窓辺で少し考え込むように立っている大ゴマ。
表情は穏やかだが、頬の片側にごく薄い光の膜がかかったような「仮面」演出。
下部に幼少期・自衛隊・現在の3つの小さなシルエットコマを配置し人生の予告とする。
暖色寄りの落ち着いた配色。

### P01 幼少期 — 兄弟の中で
昭和〜平成的な日本の家庭の居間。幼い男の子（優太、7〜9歳程度）が3人の幼い弟たちと賑やかに遊んでいるコマ。
別コマで母親が優太を叱る場面（叱っているが虐待的ではない、日常的な叱責のトーン）。
弟の一人が優太に懐いているコマ。明るい暖色の室内灯。

### P02 7歳 — 最初の別れ
コマ1: 両親・祖父母が揃った穏やかな食卓（回想トーン、やや彩度を落とす）。
コマ2: 大人たちが深刻な顔で話す様子を、廊下からそっと覗く幼い優太。
コマ3: 新しい小学校の校門前に一人立つ優太の小さな背中。
コマ4: 見知らぬ教室で俯く優太。全体に寂しさを感じる寒色寄りの配色。

### P03 小学校 — 得意なこと

コマ2: 自宅の机で夜遅くまで問題集に向かう優太（壁掛け時計で遅い時刻が分かる）。
コマ3: 家族に「もう寝なさい」と声をかけられ、少し微笑ましいやり取り。集中している時の生き生きした表情。

### P04 小学校 — 苦手なことと工夫
コマ1: 朝、プリントが見当たらず慌てる優太。
コマ2: 先生に忘れ物を指摘される場面（深刻すぎない日常描写）。
コマ3: パンパンに膨らんだランドセルに全教科書を詰め込む優太。
コマ4: 少し得意げな表情で登校する優太。

### P05 中学校 — にぎやかな日々とルールの読み方

コマ2: 提出物の束を前に気楽な表情の優太。

コマ4: 腕時計を見ながら余裕の表情の優太（先生がまだ来ないと分かっている顔）。
コマ5: 朝、友達に起こされてようやく起き上がる優太。全体的に軽快で明るいトーン。

### P06 12歳の転機 — 二度目の別れ
コマ1: 緊張した家庭内の空気（直接的暴力描写は避け、割れた食器・身をすくめる背中など示唆的表現）。
コマ2: 母をかばうように前に出る12歳頃の優太。
コマ3: 家を出ていく母子の後ろ姿、夜の住宅街。
コマ4: 少し時間が経った後の優太の複雑な表情（安堵と痛みが同居）。彩度低め、寒色寄り。

### P07 壊れた父子関係の試み
コマ1: 幼い優太が義父的存在にぎこちなく歩み寄る場面。
コマ2: 「お父さん」と呼ぼうとして言葉に詰まる優太のアップ。
コマ3: 会話のない静かな食卓（関係の冷え込みを示す構図）。
コマ4: 三度目の転校、荷物を持って新しい学校へ向かう優太の背中。

### P08 「しっかりしなきゃ」— 仮面の始まり
コマ1（大ゴマ）: 母親が優太に「助けて」と漏らす印象的な場面。
コマ2: その言葉を受け止める優太の顔、一瞬子どもらしい表情が消える。
コマ3: 鏡または窓ガラスに映る優太の顔に薄い光の膜（仮面の視覚記号）がかかる演出コマ。
このページから「仮面」モチーフを明示的に導入する。

### P09 管理の苦手さと、合う仕組み

コマ2: 空き缶にコインを入れる優太。蓋がテープで留められ簡単に取り出せない構造が分かる作画。
コマ3: 缶が少しずつ重くなっていく時間経過の演出コマ。
コマ4: 図解コマ（説明枠の空白枠のみ）。

### P10 陸上自衛隊高等工科学校 — 入学
コマ1: 校門前で緊張した面持ちの新入生の列（優太もその一人、制服姿）。
コマ2: 早朝点呼、厳しい教官の号令のある場面。
コマ3: 体力訓練の様子、厳しさが伝わる複数の小コマ。カーキ・グレーを基調にした硬質な配色。

### P11 連帯責任という構造
コマ1: 同期の誰かのミスが発覚し全員で動き出す場面。
コマ2: 優太自身のミスを仲間がフォローする対等な描写。
コマ3: 問題解決後、疲れながらも達成感のある表情。仲間との連帯感が伝わる構図。

### P12 ルールとの付き合い方

コマ3: 理不尽な指示に理屈で反論する優太と、それを苦々しく思う年上の相手。

### P13 通信の仕事 — 努力で変えられる問題
コマ1: 通信機材の前で真剣に作業する自衛官姿の優太。

### P15 板挟み — 崩れていく歯車
コマ1: 管理官交代の場面、空気が変わったことが分かる構図。

### P16 精神的に壊れた時期

コマ2: 過去の努力の記憶がフラッシュバックのように差し込まれる半透明の回想コマ。
コマ3: 図解コマ（説明枠の空白枠）。全体に最も彩度を落とした重いトーン。ただし人物は常時介助が必要な状態には描かない。

### P17 脳疲労とは何か（解説ページ）
コマ1: 頭の中に「会話」「予定」「人間関係」「正解のない問い」のアイコンが積み重なっていく図解コマ（空白の説明枠として構図のみ）。
コマ2: 相談を受ける／する場面で少しずつ消耗していく優太。
コマ3: 限界に近づいた表情のアップ。
コマ4: 強調文字用の余白を大きく取った印象的な大ゴマ。

### P18 その後の職歴 — 繰り返し現れる強み
コマ1〜5: 自衛隊（通信・整備）→コンサルティング（ヒアリング場面）→WEBデザイン／IT（教える場面）→通信・ネットワーク（基地局・設備点検）→就労移行支援（面談場面）を時系列の小コマで並べる。

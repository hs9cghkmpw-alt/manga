# Visual Reference

このディレクトリには、ユーザーが完成イメージとして指定した「見えている僕と、見えない僕」の参照画像を置く。

## 参照画像で必ず維持する要素
- 日本の学習漫画／進研ゼミ漫画に近いフルカラー表現
- 1ページ内に複数のコマ
- 人物が背景込みの場面の中で動く
- 表情・姿勢・場面そのものが情報を伝える
- 吹き出し、心の声、ナレーション、説明枠、図解、強調文字の併用
- 情報量は多いが「資料」ではなく「漫画」として読める
- 医療資料のように堅すぎない
- ギャグ漫画にはしない

## 非目標
- 元画像をそのまま分割・引き伸ばすこと
- 同じ絵を使い回すこと
- 丸い人物アイコン＋文章主体にすること
- 絵を飾りにして文章を主役にすること

## Claudeへの指示
参照画像そのものだけでなく、`CLAUDE.md` と `docs/QA_CHECKLIST.md` を必ず併読すること。

ユーザーから基準画像を受け取ったら、このディレクトリに `style_reference.jpg` または同等の明確な名称で保存し、以後の全ページ制作で参照する。

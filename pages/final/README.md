# pages/final/

校閲済み・確定済みページを置くディレクトリ。

## 用途

- `docs/QA_CHECKLIST.md` の該当項目（1ページ確定時のチェック）をすべて満たしたページのみを置く。
- ファイル名は `pages/draft/` と同じ命名規則（`P00_title.png` 等、`scripts/full_script.md` の
  ページ番号と一致）を使用する。
- ここに置かれたページは「確定」を意味する。修正が必要になった場合は、
  `pages/draft/` に戻して再校閲してから、改めてここへ昇格させる。

## 完成条件との関係

全ページがこのディレクトリに揃い、かつ `docs/QA_CHECKLIST.md` の「5. 最終PDF」項目まで
すべて満たされて初めて、`output/` へのPDF書き出しに進む。

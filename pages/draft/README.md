# pages/draft/

制作途中のページを置くディレクトリ。

## 用途

- `scripts/image_prompts.md` / `scripts/image_prompts_en.md` を使って生成した、
  校閲前のページ画像（コマ・背景・人物のみ、または日本語組版前の状態）をここに置く。
- ファイル名は `P00_title.png` のようにページ番号を先頭に付け、
  `scripts/full_script.md` のページ番号（P00〜P24）と一致させる。
- 1ページにつき、必要であれば複数の生成バリエーション（`P03_v1.png`, `P03_v2.png` 等）を
  置いてよい。採用版を決めたら `pages/final/` へ確定コピーする。

## 制作工程との関係

`CLAUDE.md` の制作工程に従い、このディレクトリのファイルは「まだ確定していない」状態を表す。
以下がすべて完了して初めて `pages/final/` へ昇格させる。

1. 画像を拡大して確認
2. 日本語全文を読む（該当ページに組版済みの場合）
3. 事実確認（`docs/QA_CHECKLIST.md` §1）
4. 構図・視線誘導確認（`docs/QA_CHECKLIST.md` §3）
5. 必要な修正

## 現在の状態

2026-09-07時点で、このディレクトリにはまだページ画像が存在しない。
画像生成には別途、画像生成ツールが利用可能な環境での作業が必要（詳細は
`docs/PROGRESS.md` の「重要な既知のギャップ」を参照）。
